# Code walkthrough

Start with the [README](../README.md) commands and [foundation configuration](../configs/foundation.toml). The package keeps data access, estimation and valuation separate so each can be exercised offline and challenged independently. `cli.main` maps explicit command arguments to these functions and prints safe status summaries; numerical artifacts stay in local output directories.

1. **Acquire and identify inputs.** `data.fetch_snapshot` reads official FRED observations under explicit vintage parameters. `intrinio` handles the permitted equity feed, and `proxy.fetch_proxy` captures the price/split and Federal Reserve monthly spread inputs. Credentials are resolved separately and never become report inputs. Canonical JSON and SHA256 identify captured content.
2. **Prepare a calendar.** `preparation` provides calendar-quarter shifts and growth transformations. `proxy.prepare_proxy` enforces common daily dates for SPY/Treasury monthly states and equal-weight monthly-to-quarter averages. Missing months and quarters remain unavailable. Inspect the prepared manifest before interpreting model sample counts.
3. **Fit candidates.** `models.fit_at_origin` filters history through the declared origin, applies the current/lag eligibility rule and fits fixed candidate specifications. `regress` scales within the window and uses reorthogonalized QR. Rank failures remain explicit. Diagnostics report residual dependence, VIF, coefficient/window changes and unstable recursion warnings.
4. **Compare chronologically.** `evaluation.partition_errors` constructs expanding and rolling origin/horizon comparisons with intermediate labels confined to their partition. `choose_models` uses one-quarter validation MAE and a deterministic tie order. `evaluate` freezes that selection before computing holdout errors. Earlier holdout targets may enter later fits but cannot select a model.
5. **Define scenarios.** `scenarios.validate_scenario` rejects ambiguous units, dates and shock references. `factor_changes` compounds incremental equity changes and differences yield/spread levels from a declared origin. Historical reconstruction, conditional macros and direct shocks remain distinct inputs.
6. **Price contractual cashflows.** `pricing.zero_rate` maps observable quotes into the disclosed two-node continuous-rate proxy. `Bond.cashflows` and `Bond.accrued` implement the synthetic contract conventions. `build_holdings` sizes once at baseline dirty values. `sensitivity` differentiates the same price function, including boundary-aware spread differences.
7. **Reconcile valuation.** `valuation.value_state` computes position, asset-class and sequential factor contributions in two orders. It checks totals before returning results. `price_scenarios` applies every cumulative state to the common baseline and receives the conditional adapter from integrated execution. Cash, time, holdings and remaining cashflows stay fixed.
8. **Capture and reproduce.** `execution.load_selection` binds the saved validation decision to data and configuration. `integrated_calculation` refits selected specifications at the baseline origin and supplies projected changes to pricing. `write_run` records inputs, outputs, source/runtime identity and checks. `load_saved_run` verifies inventory/hashes; `reproduce_run` additionally enforces the current source/runtime and compares every calculation and fit field.
9. **Generate the report.** `reporting.save_report` reads the verified saved valuation/evaluation and exports run-linked Markdown, structured pages and CSVs. `tools/render_report.py` consumes that report contract using optional ReportLab dependencies. It draws charts from the same values and guards page counts; it does not revalue holdings. Source and rendering manifests preserve their distinct provenance.

Tests execute observable behavior rather than searching source strings. Analytical bond references, equity compounding, chronological leakage boundaries, missing data, invalid domains, attribution and offline reruns are covered separately. Reporting tests compare generated CSV/chart values with synthetic engine outputs, check manifests and reject tampered bundles. See [validation status](VALIDATION_STATUS.md) for actual results and skipped remote checks.
